# Исправление проблемы с портом

## Проблема
Backend запускается на порту **8001**, а фронтенд пытается подключиться к порту **8000**.

## Решение

Файл `run.py` исправлен - порт изменен с 8001 на 8000.

**ВАЖНО:** Перезапустите приложение:
1. Остановите текущий процесс (Ctrl+C)
2. Запустите снова: `python run.py`
3. Проверьте логи - должно быть: `Uvicorn running on http://127.0.0.1:8000`

## Проверка

После перезапуска проверьте:
- ✅ Backend: `http://localhost:8000/docs` - должна открыться Swagger документация
- ✅ Frontend: `http://localhost:5173` - должна загрузиться админ-панель
- ✅ API запросы должны работать без ошибок `ERR_CONNECTION_REFUSED`

## Если проблема сохраняется

Если после перезапуска backend все еще на 8001:
1. Проверьте, что файл `run.py` сохранен
2. Убедитесь, что вы запускаете правильный файл
3. Проверьте, нет ли другого процесса, который запускает backend на 8001
