## 💡 Быстрый старт для продакшена

Если нужно запустить быстро:

1. **Создайте `.env` файл:**
```env
BOT_TOKEN=ваш_токен
BOT_ADMIN_ID=7229606042
DB_USER=video_user
DB_PASSWORD=надежный_пароль
DB_HOST=localhost
DB_PORT=5432
DB_NAME=video_editor_bot
OPENROUTER_API_KEY=ваш_ключ
JWT_SECRET_KEY=очень-длинный-случайный-ключ-минимум-32-символа
```

2. **Используйте только `.env`, удалите `app/config.py` из git**

3. **Настройте Redis для FSM**

4. **Обновите CORS на продакшен домены**

5. **Настройте логирование**

После этого проект будет готов к использованию в продакшене! 🎉
