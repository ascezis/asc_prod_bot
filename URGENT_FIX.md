# 🔴 СРОЧНОЕ ИСПРАВЛЕНИЕ - Порт Backend

## Проблема
Backend запускается на порту **8001**, а фронтенд пытается подключиться к порту **8000**, из-за чего возникают ошибки:
- `ERR_CONNECTION_REFUSED`
- Swagger не открывается
- Данные не загружаются во фронтенд

## Решение (ВЫПОЛНИТЕ СЕЙЧАС)

### Вариант 1: Исправление вручную (быстро)

1. Откройте файл `run.py` в редакторе
2. Найдите строку 121:
   ```python
   [sys.executable, "-m", "uvicorn", "admin.backend.main:app", "--reload", "--port", "8001"],
   ```
3. Замените `"8001"` на `"8000"`:
   ```python
   [sys.executable, "-m", "uvicorn", "admin.backend.main:app", "--reload", "--port", "8000"],
   ```
4. Сохраните файл
5. **Перезапустите приложение** (Ctrl+C и затем `python run.py`)

### Вариант 2: Использование скрипта

Запустите в PowerShell (из корня проекта):
```powershell
python fix_port.py
```

Затем перезапустите приложение.

## Проверка

После перезапуска в логах должно быть:
```
[Backend] INFO:     Uvicorn running on http://127.0.0.1:8000
```

А не:
```
[Backend] INFO:     Uvicorn running on http://127.0.0.1:8001  ❌
```

## После исправления

1. ✅ Откройте `http://localhost:8000/docs` - должна открыться Swagger документация
2. ✅ Откройте `http://localhost:5173` - фронтенд должен загрузить данные
3. ✅ Ошибки `ERR_CONNECTION_REFUSED` должны исчезнуть
