# Создание пользователей (Admin, User)

После создания первого пользователя-владельца (Owner), вы можете создать пользователей с другими ролями.

## 🚀 Способ 1: Через скрипт (рекомендуется)

Самый простой способ - использовать скрипт:

```bash
python scripts/create_user.py
```

Скрипт попросит ввести:
- **Username** - имя пользователя
- **Email** - email адрес
- **Password** - пароль
- **Роль** - выберите 1 (user), 2 (admin) или 3 (owner)

### Пример:

```
=== Создание пользователя ===
Username: admin_user
Email: admin@example.com
Password: secure_password123

Выберите роль:
1 - user
2 - admin
3 - owner
Роль (1/2/3): 2

[SUCCESS] Пользователь создан!
  ID: 2
  Username: admin_user
  Email: admin@example.com
  Role: admin
```

---

## 🌐 Способ 2: Через API (Swagger UI)

1. **Войдите в админ-панель под Owner аккаунтом**

2. **Откройте Swagger UI:** `http://localhost:8000/docs`

3. **Найдите endpoint:** `POST /auth/register`

4. **Нажмите "Try it out"**

5. **Введите данные:**
```json
{
  "username": "admin_user",
  "email": "admin@example.com",
  "password": "secure_password123",
  "role": "admin"
}
```

6. **Нажмите "Execute"**

**Важно:** Для использования этого endpoint нужен токен Owner. Swagger автоматически добавит токен, если вы авторизованы.

---

## 🔧 Способ 3: Через API (curl)

Если у вас есть токен Owner:

```bash
curl -X POST "http://localhost:8000/auth/register" \
  -H "Authorization: Bearer YOUR_OWNER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin_user",
    "email": "admin@example.com",
    "password": "secure_password123",
    "role": "admin"
  }'
```

### Как получить токен Owner:

1. Войдите в админ-панель под Owner
2. Откройте консоль браузера (F12)
3. Выполните: `localStorage.getItem('auth_token')`
4. Скопируйте токен

## 📋 Доступные роли

### `user` - Заказчик
- Может просматривать свою информацию
- Может просматривать свои проекты
- **Не может:** создавать, редактировать, удалять данные

### `admin` - Администратор
- Полный доступ к админ-панели
- Может просматривать всех клиентов и проекты
- Может создавать и редактировать клиентов и проекты
- Может просматривать статистику
- **Не может:** удалять клиентов/проекты, создавать пользователей

### `owner` - Владелец
- Все права Admin
- Может удалять клиентов и проекты
- Может создавать новых пользователей
- Полный контроль над системой

---

## 🔐 Вход под созданным пользователем

После создания пользователя:

1. **Выйдите из текущего аккаунта** (кнопка "Выход" в сайдбаре)

2. **Введите данные нового пользователя:**
   - Username
   - Password

3. **Нажмите "Войти"**

Теперь вы вошли под новым пользователем с соответствующими правами!

---

## ⚠️ Важные замечания

- **Только Owner может создавать пользователей** через API
- Скрипт `create_user.py` может создавать пользователей с любой ролью напрямую в БД
- Пароли хранятся в зашифрованном виде (bcrypt)
- Email и Username должны быть уникальными

---

## 🐛 Решение проблем

### Ошибка "Username already registered"
- Пользователь с таким username уже существует
- Выберите другое имя

### Ошибка "Email already registered"
- Пользователь с таким email уже существует
- Используйте другой email

### Ошибка 401 (Unauthorized) при использовании API
- Убедитесь, что вы вошли под Owner аккаунтом
- Проверьте, что токен не истек (действует 30 дней)
