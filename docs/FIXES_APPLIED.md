# Исправления проблем

## Проблемы из логов:

### 1. ❌ Backend запускается на порту 8001 вместо 8000

**Решение:** 
- Файл `run.py` уже исправлен (порт 8000)
- **Перезапустите приложение** - остановите текущий процесс (Ctrl+C) и запустите снова:
```bash
python run.py
```

### 2. ❌ Ошибка уведомления: "chat not found"

**Причина:** Администратор (ID: 7229606042) не начал диалог с ботом.

**Решение:**
1. Администратор должен написать боту @SuperGenius22299Bot команду `/start`
2. После этого бот сможет отправлять уведомления

**Важно:** Telegram требует, чтобы пользователь сначала написал боту, прежде чем бот сможет ему писать.

### 3. ❌ Данные не приходят во фронтенд

**Причина:** Backend запущен на порту 8001, а фронтенд ожидает 8000.

**Решение:**
1. Перезапустите приложение (см. пункт 1)
2. Убедитесь, что backend запущен на порту 8000
3. Проверьте в браузере: `http://localhost:8000/docs` - должна открыться документация API

### 4. ❌ .env файл не найден

**Где находится .env файл:**
- Файл `.env` должен быть в **корне проекта** (там же, где `run.py`)
- Файл находится в `.gitignore`, поэтому его нет в репозитории

**Как создать:**
1. Создайте файл `.env` в корне проекта
2. Скопируйте содержимое из `ENV_SETUP.md` или используйте этот шаблон:

```env
# Telegram Bot Configuration
BOT_TOKEN=your_bot_token_here
BOT_ADMIN_ID=7229606042

# Database Configuration
DB_USER=video_user
DB_PASSWORD=ascezis_pass
DB_HOST=localhost
DB_PORT=5432
DB_NAME=video_editor_bot

# OpenRouter AI Configuration
OPENROUTER_API_KEY=your_openrouter_api_key_here
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1/chat/completions
```

3. Заполните все значения (особенно `BOT_TOKEN` и `OPENROUTER_API_KEY`)
4. Перезапустите приложение
