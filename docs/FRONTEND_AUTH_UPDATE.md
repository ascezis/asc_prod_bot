## 🚀 Как это работает

1. **При загрузке приложения:**
   - Проверяется наличие токена в localStorage
   - Если токен есть - показывается основной интерфейс
   - Если токена нет - показывается страница входа

2. **При входе:**
   - Пользователь вводит username и password
   - Отправляется запрос на `/auth/login`
   - Токен и информация о пользователе сохраняются в localStorage
   - Происходит редирект на главную страницу

3. **При API запросах:**
   - `apiClient` автоматически добавляет заголовок `Authorization: Bearer <token>`
   - Если токен невалиден (401) - автоматический редирект на логин

4. **При выходе:**
   - Токен и пользователь удаляются из localStorage
   - Страница перезагружается, показывается форма входа
