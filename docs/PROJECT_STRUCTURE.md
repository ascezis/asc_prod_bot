# Структура проекта

```
asc_prod_bot/

│   ├── bot/                   # Логика бота

│   ├── database/              # Модели БД
│   ├── services/              # Сервисы (AI, уведомления)
│   ├── config.py             # Конфигурация (в .gitignore)
│   └── main.py               # Точка входа бота
│
├── 📁 admin/                  # Админ-панель
│   ├── backend/               # FastAPI Backend
│   │   ├── routers/           # API endpoints
│   │   ├── auth.py           # Аутентификация
│   │   └── main.py           # Точка входа API
│   └── frontend/              # React Frontend
│       └── src/
│           ├── api/          # API клиенты
│           ├── pages/        # Страницы
│           └── components/   # Компоненты
│
├── 📁 docs/                    # 📚 Документация
│   ├── README.md             # Навигация по документации
│   ├── AI_CONTEXT.md         # Контекст для AI
│   ├── QUICK_START.md        # Быстрый старт
│   ├── AUTHENTICATION_GUIDE.md # Руководство по аутентификации
│   └── ...                   # Другая документация
│
├── 📁 scripts/                # 🔧 Вспомогательные скрипты
│   ├── README.md             # Описание скриптов
│   ├── create_owner_simple.py # Создание владельца
│   ├── test_*.py             # Тестовые скрипты
│   └── ...                   # Другие утилиты
│
├── 📁 sql/                    # 📋 SQL скрипты
│   ├── README.md             # Описание SQL скриптов
│   └── create_users_table.sql # Создание таблицы users
│
├── 📄 README.md               # Главный README
├── 📄 requirements.txt        # Python зависимости
├── 📄 run.py                  # Запуск всех компонентов
└── 📄 .gitignore              # Игнорируемые файлы
```

## Основные папки

### `app/` - Telegram бот
- Логика работы бота
- Обработчики команд и состояний
- Интеграция с AI для анализа заявок

### `admin/backend/` - FastAPI Backend
- REST API для админ-панели
- Аутентификация и авторизация
- Работа с БД

### `admin/frontend/` - React Frontend
- Админ-панель
- Управление клиентами и проектами
- Статистика

### `docs/` - Документация
- Вся документация проекта
- Руководства и инструкции
- Контекст для AI

### `scripts/` - Скрипты
- Утилиты для создания пользователей
- Тестовые скрипты
- Вспомогательные инструменты

### `sql/` - SQL скрипты
- Скрипты для создания таблиц
- Миграции (если используются)

---

**Примечание:** Конфигурационные файлы (`app/config.py`, `.env`) должны быть в `.gitignore` и не коммититься в репозиторий.
