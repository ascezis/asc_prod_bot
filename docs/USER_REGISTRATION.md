# Регистрация и управление пользователями

## 🎯 Обзор

Система поддерживает:
- **Публичную регистрацию** для обычных пользователей (роль `user`)
- **Управление пользователями** для Admin и Owner
- **Выдачу админок** (повышение роли до `admin`)

---

## 📝 Публичная регистрация

### Для пользователей

Любой пользователь может зарегистрироваться самостоятельно:

1. **Откройте страницу регистрации:**
   - Перейдите на `/register` или нажмите "Зарегистрироваться" на странице входа

2. **Заполните форму:**
   - Username (уникальный)
   - Email (уникальный)
   - Password (минимум 6 символов)
   - Подтвердите пароль

3. **После регистрации:**
   - Пользователь автоматически получает роль `user`
   - Можно сразу войти в систему
   - Доступен просмотр своей информации

### API Endpoint

```http
POST /auth/register
Content-Type: application/json

{
  "username": "new_user",
  "email": "user@example.com",
  "password": "password123"
}
```

**Ответ:**
```json
{
  "id": 1,
  "username": "new_user",
  "email": "user@example.com",
  "role": "user",
  "is_active": true
}
```

## 👤 Управление пользователями

### Для Admin и Owner

Только пользователи с ролью `admin` или `owner` могут:

- **Просматривать список пользователей**
- **Редактировать email пользователей**
- **Повышать роль до `admin`** (только Owner)
- **Активировать/деактивировать пользователей** (только Owner)
- **Удалять пользователей** (только Owner)

### Страница управления

1. **Войдите под Admin или Owner**

2. **Откройте раздел "Пользователи"** в сайдбаре

3. **Доступные действия:**
   - Поиск по username или email
   - Фильтрация по роли
   - Редактирование пользователя
   - Удаление пользователя (только Owner)

### API Endpoints

#### Список пользователей
```http
GET /users?search=username&role=admin&limit=100&offset=0
Authorization: Bearer <admin_token>
```

#### Получить пользователя
```http
GET /users/{user_id}
Authorization: Bearer <admin_token>
```

#### Обновить пользователя
```http
PUT /users/{user_id}
Authorization: Bearer <owner_token>
Content-Type: application/json

{
  "email": "newemail@example.com",
  "role": "admin",  // Только Owner может менять
  "is_active": true  // Только Owner может менять
}
```

#### Удалить пользователя
```http
DELETE /users/{user_id}
Authorization: Bearer <owner_token>
```

## 🔐 Выдача админок

### Как повысить пользователя до Admin

**Только Owner может это сделать:**

1. Войдите под Owner аккаунтом

2. Откройте раздел "Пользователи"

3. Найдите нужного пользователя

4. Нажмите кнопку редактирования (✏️)

5. В поле "Роль" выберите `admin`

6. Нажмите "Сохранить"

Теперь пользователь может войти и получить доступ к админ-панели!

### Через API

```http
PUT /users/{user_id}
Authorization: Bearer <owner_token>
Content-Type: application/json

{
  "role": "admin"
}
```

## 🚀 Примеры использования

### Сценарий 1: Новый пользователь регистрируется

1. Пользователь переходит на `/register`
2. Заполняет форму регистрации
3. Получает роль `user`
4. Может войти и просматривать свою информацию

### Сценарий 2: Owner выдает админку

1. Owner входит в систему
2. Открывает раздел "Пользователи"
3. Находит пользователя с ролью `user`
4. Редактирует и меняет роль на `admin`
5. Пользователь теперь может войти как Admin

### Сценарий 3: Admin просматривает пользователей

1. Admin входит в систему
2. Открывает раздел "Пользователи"
3. Видит список всех пользователей
4. Может искать и фильтровать
5. Может редактировать email (но не роль)

---

## ⚠️ Важные замечания

- **Только Owner может менять роли** пользователей
- **Нельзя удалить самого себя** (Owner не может удалить свой аккаунт)
- **Email должен быть уникальным** при редактировании
- **Пароли хранятся в зашифрованном виде** (bcrypt)
- **Роль по умолчанию** для публичной регистрации - `user`

## 🔧 Технические детали

### Backend

- `POST /auth/register` - публичная регистрация (только роль `user`)
- `POST /auth/register/admin` - регистрация с любой ролью (только Owner)
- `GET /users` - список пользователей (Admin/Owner)
- `PUT /users/{id}` - обновление пользователя
- `DELETE /users/{id}` - удаление пользователя (только Owner)

### Frontend

- `/register` - страница регистрации
- `/users` - страница управления пользователями (Admin/Owner)
- Автоматическое добавление пункта "Пользователи" в сайдбар для Admin/Owner
